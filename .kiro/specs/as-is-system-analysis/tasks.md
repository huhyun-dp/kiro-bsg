# Implementation Plan: as-is-system-analysis

## Overview

AS-IS 시스템 분석 결과를 검토·확인·보완하기 위한 체크리스트다. 코드를 수정하거나 새로운 기능을 개발하지 않는다. 업무 담당자 확인 사항, 문서 보완, 구현 불일치 점검, 미검증 기능 목록, 향후 개선 후보 항목으로 구성된다.

## Tasks

- [ ] 1. 업무 담당자 확인 사항
  - [ ] 1.1 회원 관리 화면 접근 정책 확인
    - 현재 로그인한 모든 회원이 전체 회원 목록을 조회할 수 있다. 내부 운영 담당자만 가입하는 시스템인지, 또는 일반 회원과 관리자를 구분해야 하는지 확인한다.
  - [ ] 1.2 오류 화면 관리자 연락처 현행화 확인
    - 오류 화면(`error.html`)에 `02-6730-3200`이 고정값으로 기재되어 있다. 현재도 유효한 연락처인지 확인한다. 변경이 필요하면 개발자에게 수정 요청이 필요하다.
  - [ ] 1.3 운영 환경 보안 설정 적용 확인
    - 운영 서버(HTTPS 환경)에서 `SESSION_COOKIE_SECURE=true`가 설정되어 있는지 확인한다. 미설정 시 보안 위험이 있다.
  - [ ] 1.4 운영 환경 데모 데이터 비활성화 확인
    - 운영 서버에서 `SEED_DEMO_MEMBERS=false`가 설정되어 테스트용 회원 100명이 생성되지 않도록 설정되어 있는지 확인한다.
  - [ ] 1.5 회원 관리 화면의 실제 주 사용자 확인
    - 현재 분석에서 "내부 운영 담당자 전용 관리 화면"으로 추정하였다. 실제 비즈니스 목적과 사용 대상이 맞는지 PI/PO가 확인하여 문서에 반영한다.

- [ ] 2. 문서 보완 사항
  - [ ] 2.1 회원 관리 화면 접근 정책 결론 반영
    - 항목 1.1 확인 후 요구사항 문서(requirements.md)의 "사용자" 및 "접근 제어" 항목을 확정된 내용으로 업데이트한다.
  - [ ] 2.2 이용약관 및 개인정보 처리방침 내용 확인
    - 가입 화면에 약관 동의 체크박스가 있으나, 약관 본문 링크나 내용이 현재 시스템에 없다. 약관 내용과 제공 방식을 확인하여 문서에 추가한다.
  - [ ] 2.3 그리드 UI 인터넷 의존성 확인
    - 회원 목록 화면은 TOAST UI Grid를 인터넷 CDN에서 로딩한다. 폐쇄망 또는 인터넷 제한 환경에서 운영하는 경우 별도 대응이 필요한지 확인하여 설계 문서에 기재한다.

- [ ] 3. 문서와 실제 구현이 다른 항목 점검
  - [ ] 3.1 기능 변경 시 README.md와 Spec 문서 동시 업데이트 정책 수립
    - 현재 검토 결과 README.md와 실제 구현 간 불일치는 발견되지 않았다. 코드 변경 후 README와 Spec 문서가 구현과 어긋나지 않도록 업데이트 절차를 정한다.

- [ ] 4. 테스트로 확인되지 않은 현재 기능
  - [ ] 4.1 이메일 중복 가입 방지 (오류 메시지 표시)
  - [ ] 4.2 비밀번호 확인 불일치 처리
  - [ ] 4.3 약관 미동의 시 가입 차단
  - [ ] 4.4 회원가입 완료 후 로그인 화면 안내 메시지 표시
  - [ ] 4.5 로그인 실패 오류 메시지 표시
  - [ ] 4.6 이미 로그인 상태에서 로그인/가입 화면 접근 시 회원 관리 화면 이동
  - [ ] 4.7 세션 만료(30분) 후 자동 로그인 화면 이동
  - [ ] 4.8 로그아웃 처리 및 세션 무효화 확인
  - [ ] 4.9 CSRF 토큰 불일치 시 403 응답 확인
  - [ ] 4.10 회원 목록 전체 조회 (키워드 없음)
  - [ ] 4.11 키워드 검색 (이름, 이메일, 휴대폰 번호 각각)
  - [ ] 4.12 검색 결과 대소문자 무시 확인
  - [ ] 4.13 API 미인증 접근 시 401 JSON 응답 확인
  - [ ] 4.14 타이밍 공격 방지 동작 확인 (더미 비밀번호 비교)

- [ ] 5. 향후 개선 검토 후보
  - [ ] 5.1 회원 정보 수정 기능 (이름, 휴대폰 번호 변경)
  - [ ] 5.2 비밀번호 변경 기능
  - [ ] 5.3 비밀번호 찾기 / 재설정 (이메일 발송 포함)
  - [ ] 5.4 회원 삭제 또는 비활성화 기능
  - [ ] 5.5 권한 등급 구분 (일반 회원 vs 관리자)
  - [ ] 5.6 목록 페이지네이션 — 현재는 전체 목록을 한 번에 표시
  - [ ] 5.7 로그인 실패 횟수 제한 (계정 잠금 정책)
  - [ ] 5.8 회원 상세 정보 화면
  - [ ] 5.9 엑셀 내보내기
  - [ ] 5.10 CDN 의존성 제거 (TOAST UI Grid를 서버에 직접 포함)
  - [ ] 5.11 이용약관 및 개인정보 처리방침 화면 제공
  - [ ] 5.12 관리자 연락처를 환경변수로 분리하여 코드 수정 없이 변경 가능하도록 개선

## Notes

- 이 문서는 AS-IS 시스템 분석 결과이며, 개발 구현 작업이 아닌 확인·검토·보완 체크리스트다
- 섹션 1~2는 업무 담당자(PI/PO)가 확인해야 할 항목이다
- 섹션 2는 섹션 1의 확인 결과를 반영하여 문서를 보완하는 후속 작업이므로, 1 → 2 순서로 진행한다
- 섹션 4는 현재 구현된 기능이나 자동 테스트가 없는 항목들이다. 테스트 추가 여부는 별도 판단한다
- 섹션 5는 현재 존재하지 않는 기능이다. 현재 기능과 혼동하지 않도록 개발 여부는 별도로 결정한다
