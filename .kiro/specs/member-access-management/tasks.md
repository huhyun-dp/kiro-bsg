# Implementation Plan: member-access-management

## Overview

권한 관리 기능은 이미 구현·검증·커밋되어 있다. 본 체크리스트는 (1) 구현이 요구사항을 충족했는지 확인하는 항목과 (2) PI/PO·운영 담당자가 확인·결정할 항목, (3) 향후 개선 후보로 구성된다. 기존 `member-auth-baseline` 스펙과 동일하게, 이 문서는 임의로 코드를 수정하지 않으며 확인·보완을 목적으로 한다.

- `[x]` — 구현 완료 및 테스트로 확인된 항목
- `[ ]` — 담당자 확인 또는 향후 결정이 필요한 항목

## 기존 as-is 스펙과의 관계

- `member-auth-baseline` 스펙의 확인 항목 **Q1**(권한 구분 필요 여부)은 본 기능 도입으로 해소되었다.
- `member-auth-baseline`은 권한 구분 이전의 초기 스냅샷으로 보존하며, 본 스펙이 권한 관리 확장을 담당한다.
- 두 스펙이 겹치는 접근 제어 서술은 본 스펙(member-access-management)을 우선 참조한다.

## Task Dependency Graph

`waves`는 함께 수행 가능한 작업 묶음을 선행 순서대로 나열한다. 앞 wave가 완료되어야 다음 wave를 진행한다.

```json
{
  "waves": [
    { "id": 0, "tasks": ["1.1", "1.2", "1.3", "1.4"] },
    { "id": 1, "tasks": ["2.1", "2.2", "2.3", "3.1", "3.2", "3.3", "3.4", "3.5", "4.1", "4.2", "4.3", "4.4", "5.1", "5.2", "5.3", "5.4"] },
    { "id": 2, "tasks": ["6.1", "6.2", "6.3", "6.4", "6.5"] },
    { "id": 3, "tasks": ["7.1", "7.2", "7.3", "7.4"] },
    { "id": 4, "tasks": ["8.1", "8.2"] },
    { "id": 5, "tasks": ["9.1", "9.2", "9.3", "9.4", "9.5", "9.6", "10.1", "10.2", "10.3", "10.4"] }
  ]
}
```

- wave 0(스키마)이 모든 기능 작업의 선행이다.
- wave 1의 API(4.x) 이후 wave 2의 화면(6.x)이 계약에 의존한다.
- wave 3(테스트) → wave 4(문서) 순으로 검증·정리한다.
- wave 5(9·10)는 구현과 독립적인 PI/PO 의사결정·백로그로 마지막에 둔다.
