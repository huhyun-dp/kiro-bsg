========================================================================
 AWS API MCP - EC2 인스턴스 조회 및 종료(Terminate) 작업 보고서
========================================================================

작성 목적 : AWS API MCP 도구를 통한 EC2 조회/종료 테스트의 전 과정을
            제3자에게 설명 가능하도록 기록한다.
대상 리전 : ap-northeast-2 (서울)
대상 대상 : EC2 인스턴스 i-0c6a1c8c5e9b0a29d (Name: bsg-mcp-test)
사용 도구 : mcp_aws_api_call_aws  (@aws-api/call_aws)
            ※ 로컬 AWS CLI는 일절 사용하지 않음. 전부 MCP 경유.


------------------------------------------------------------------------
[0] 사전 확인 - MCP 도구 주입 여부
------------------------------------------------------------------------
현재 세션에 아래 2개의 AWS API MCP 도구가 주입되어 사용 가능함을 확인.

  - mcp_aws_api_call_aws          (@aws-api/call_aws)
      : AWS CLI 명령을 검증 후 실제 실행하는 도구
  - mcp_aws_api_suggest_aws_commands (@aws-api/suggest_aws_commands)
      : 자연어 요청에 맞는 AWS CLI 명령을 추천하는 fallback 도구

이번 작업에서는 mcp_aws_api_call_aws 만 사용함.


------------------------------------------------------------------------
[1] 1차 조회 - 인스턴스 상세 정보 확인 (읽기 전용)
------------------------------------------------------------------------
사용 도구 : mcp_aws_api_call_aws
AWS API   : EC2 DescribeInstances
실행 명령 :
  aws ec2 describe-instances \
      --instance-ids i-0c6a1c8c5e9b0a29d \
      --region ap-northeast-2

조회 결과 vs 생성 당시 기준 비교:

  항목            조회된 값                    비교 기준                    일치
  --------------  ---------------------------  ---------------------------  ----
  Instance ID     i-0c6a1c8c5e9b0a29d          i-0c6a1c8c5e9b0a29d          O
  Instance State  running                      (기준 미지정)                -
  Instance Type   t3.micro                     t3.micro                     O
  Private IP      172.31.3.44                  172.31.3.44                  O
  Public IP       없음(빈 값)                  없음                         O
  AMI ID          ami-0c97793ee5ea0967f        ami-0c97793ee5ea0967f        O
  AZ              ap-northeast-2a              ap-northeast-2a              O
  Name 태그       bsg-mcp-test                 bsg-mcp-test                 O

결론 : 비교 기준 7개 항목 전부 일치. 조회 시점 상태는 running.


------------------------------------------------------------------------
[2] 2차 조회 - 종료 직전 재확인 (읽기 전용)
------------------------------------------------------------------------
사용 도구 : mcp_aws_api_call_aws
AWS API   : EC2 DescribeInstances
목적      : 종료 실행 전, 대상이 존재하고 running 상태인지 재확인

확인 결과:
  Instance ID : i-0c6a1c8c5e9b0a29d
  State       : running
  Type        : t3.micro
  Name        : bsg-mcp-test
  AZ          : ap-northeast-2a

결론 : 대상 인스턴스 존재 및 running 상태 확인 완료.


------------------------------------------------------------------------
[3] 최종 승인 게이트
------------------------------------------------------------------------
- Terminate는 되돌릴 수 없는 파괴적 작업이므로, 실행 전 사용자에게
  최종 승인을 요청함.
- 사용자가 명시적으로 "승인. terminate 진행"으로 답변함.
- 승인 이후에만 종료를 실행함.


------------------------------------------------------------------------
[4] 종료 실행 - TerminateInstances
------------------------------------------------------------------------
사용 도구 : mcp_aws_api_call_aws
AWS API   : EC2 TerminateInstances
실행 명령 :
  aws ec2 terminate-instances \
      --instance-ids i-0c6a1c8c5e9b0a29d \
      --region ap-northeast-2

응답 결과:
  InstanceId    : i-0c6a1c8c5e9b0a29d
  PreviousState : running       (Code 16)
  CurrentState  : shutting-down (Code 32)

결론 : 종료 요청 정상 수락. running -> shutting-down 전환.


------------------------------------------------------------------------
[5] 종료 후 최종 상태 확인 (읽기 전용)
------------------------------------------------------------------------
사용 도구 : mcp_aws_api_call_aws
AWS API   : EC2 DescribeInstances

확인 결과:
  Instance ID : i-0c6a1c8c5e9b0a29d
  State       : shutting-down
  Type        : t3.micro
  Name        : bsg-mcp-test
  AZ          : ap-northeast-2a

참고 : shutting-down 상태이며, 잠시 후 자동으로 terminated 로 전환됨.
       루트 EBS 볼륨(vol-0667ab25c808bb22b)은 DeleteOnTermination=true
       설정이라 인스턴스 종료와 함께 삭제됨.


------------------------------------------------------------------------
[요약]
------------------------------------------------------------------------
  단계  도구                   AWS API             결과
  ----  ---------------------  ------------------  --------------------------
  1     mcp_aws_api_call_aws   DescribeInstances   running / 기준 7항목 일치
  2     mcp_aws_api_call_aws   DescribeInstances   running (종료 직전 재확인)
  3     (사용자 승인)          -                   "승인. terminate 진행"
  4     mcp_aws_api_call_aws   TerminateInstances  running -> shutting-down
  5     mcp_aws_api_call_aws   DescribeInstances   shutting-down

안전 준수 사항:
  - 모든 호출은 mcp_aws_api_call_aws (MCP) 경유. 로컬 AWS CLI 미사용.
  - 대상은 i-0c6a1c8c5e9b0a29d 단 한 대. 다른 리소스는 건드리지 않음.
  - 파괴적 작업(Terminate)은 사용자 명시 승인 이후에만 실행함.
